# ctxr visual identity

The logo is the lowercase wordmark alone: Azeret Mono 650, optical spacing and a split x. No separate symbol appears in the logo, app icon or favicon.

| Token | Value |
| --- | --- |
| Carbon | `#151714` |
| Chalk | `#F5F7F2` |
| Citron | `#C4F25A` |
| Supporting type | Azeret Mono 400 / 500 |

Use citron lettering on carbon, carbon lettering on chalk, and carbon text on citron surfaces. Light and dark variants preserve the same composition. Large typography, negative space and an authentic timestamped video frame explain the product without decorative effects.

The social card is 1280 × 640; the README banner is 1600 × 400. Both use the original Rickroll sample and preserve its source colors. The README also retains the tagline as selectable text.

Use the supplied outlined vectors instead of retyping the logo. Keep proportions and clear space; use the wordmark at least 80 px wide except in favicon slots. Prefer the 32 px favicon where supported.
